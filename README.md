# 🔴 LFC Trivia Quiz

An interactive web application designed specifically for fans of Liverpool FC to test their knowledge of the club's history, legends, and triumphs.

---

## ✨ Project Features

* **Diverse Questions:** Covers Liverpool FC's history, legends, and iconic trophy wins.
* **Club-Inspired Interface:** A sleek design reflecting the "Reds'" visual identity, featuring the signature red color scheme.
* **Instant Scoring System:** Tracks the score in real-time with every correct answer and displays a final summary report.
* **Real-Time Interaction:** Seamless, dynamic updates of questions and buttons without the need to reload the page.

---

## 🛠️ Technologies Used

* **HTML5:** Structures page elements, option buttons, and the question container.
* **CSS3:** Styles the interface and buttons, and applies the color scheme.
* **JavaScript (Vanilla):** Manages game logic, tracks the current question, and dynamically updates the content.
